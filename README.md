# 金蝙蝠2号 · 精简数据版

一个网页，配两份完整文档。核心是30M标准范式复核、行业雷达、账户持仓及盘后收益核对。

| 文件 | 内容 |
|---|---|
| [index.html](index.html) | 主网页，内嵌信号、量化、历史资料和交互曲线 |
| [产品文档.md](产品文档.md) | 页面功能、流程、业务规则、边界与验收 |
| [数据与接口文档.md](数据与接口文档.md) | 数据来源、字段、接口格式、接入步骤和后台开发要求 |
| README.md | 使用说明 |

## 使用

下载后打开index.html即可查看内置资料。连接API时推荐HTTPS静态托管或本地HTTP服务；源码不需要前端依赖和构建。GitHub文件页面显示代码，不能代替网页运行。

## 本版精简

根目录只有4个文件。不附逐页图片、PDF、Excel和重复JSON；保留已经核验的结构化数值、信号和历史日期。完整原件留在旧仓库作为备份。

数据截至时间以页面所选交易日为准；2026-10-23是文档整理日期，不代表新增了该日信号或报告。

## 后续接数据

先接一个聚合V2 JSON接口，再接独立指数行情和波形URL。具体字段见数据文档。钉钉采集、账户同步、团队鉴权、雷达长期历史在线适配和无人值守任务需要后台开发；网页保留接入口不代表这些服务已上线。

仓库包含内部研究数据，使用Private。当前未启用公开GitHub Pages，公开演示前应先移除或脱敏真实账户与持仓资料。
